# 架构决策记录(ADR)

本目录记录项目的关键架构决策及其理由。

## 约定

- 决策一经记录不做静默修改。判断发生变化时,**新增 ADR 记录反转并标注影响的旧记录**,保留完整的决策链路
- 每条 ADR 包含:背景、问题、决策、理由、备选方案、后果、触发条件
- 状态:`已采纳` / `已废弃` / `被 ADR-xxx 取代`
